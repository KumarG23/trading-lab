## Intake and availability

`scripts/import_catalyst_events.py` accepts JSONL fields `provider,url,symbol,kind,published_at,text` with `kind=earnings|guidance`. It assigns the actual local `first_seen_at` and `available_at` at import, canonical UTC, never accepting a caller-provided earlier observation. SHA-256 binds text and source-key identity; duplicate imports skip, changed content for the same identity fails, tampering fails on read. The input `text` may be an excerpt; the `provider` must state that honestly. The ignored ledger is `data/events/catalysts-v1.jsonl`. An imported historical release is **not** historical backtest evidence: earlier quote availability, text-vintage, and source distribution cannot be reconstructed by setting its filing timestamp. The AZO SEC exhibit headline imported as a smoke test has publication time set to the EDGAR *acceptance time*, not an assertion that this was the first public announcement; its actual available_at is the import timestamp.

`scripts/v3_source_probe.py` now supports one-shot `--sec-eligible` (all 44 with 0.6-second pacing), `--sec-core` (24), and `--capture-news` (all 44, a complete bounded 24-hour paginated snapshot). Run via `.venv/bin/python -m scripts.v3_source_probe` with the chosen flag; SEC requires `SEC_CONTACT_EMAIL` supplied only in the process environment (never in Git), Alpaca reads the private `.env`. News snapshots are private ignored files under `data/events/news-snapshots/`; they include every returned eligible story, not just keyword leads, source creation/update time, completed-request observation time, universe fingerprint, and explicit ineligibility for historical backtests. Alpaca sometimes returns an older-created story updated within the query window: preserve it as `created_in_requested_window=false`, never classify it as a new earnings lead. No automated news-to-trade conversion, cron, or broker order code exists. On 2026-09-22 a complete 24-hour snapshot contained 85 stories, including 84 created in the requested window, one older updated story, and two **unverified keyword leads**. A 44-issuer SEC 7-day sweep completed with zero qualifying exhibits in that interval; zero is a result, not grounds to widen the class. A separate AZO smoke test confirmed the actual EX-99.1 press-release text (not merely its 8-K cover) is captured forward-only.

SEC submissions acceptance timestamps can carry `Z` while showing the same wall-clock value on the EDGAR filing page; use the raw complete-submission `<ACCEPTANCE-DATETIME>` Eastern header and compare the clocks, with `first_seen_at` assigned at actual import. A 2026-09-22 AZO API-`Z` timestamp was four hours earlier than the raw-header UTC conversion; the erroneous local prototype row was quarantined under ignored `data/events/`, not silently promoted. The earlier read-only probe returned recent and 2025 historical AZO news plus IEX/SIP historical minute bars in tiny samples; that does not prove real-time SIP entitlement, news latency, historical completeness, or redistribution rights. Do not infer a historical trade from a freshly retrieved old article.

Before scheduling recurring acquisition, establish robust per-source failure/retry and skipped-exhibit telemetry, article syndication deduplication and provider usage terms, and benchmark real-time prices/spreads and receipt latency. SEC timestamps, newswire timestamps, and our observation are distinct. News sentiment and LLM features are forward-only unless the model's training cutoff is provably before each historical decision. Model outputs must quote the source spans used and carry model/version, prompt/schema, input hash, and inference time. Text is untrusted data, never instructions.

## Evidence gate before learner/forward loop

Require point-in-time event identity, release/first-seen/decision cutoffs, matched completed market/sector/stock bars and conservative spreads, fixed entry window after actual observation, no-fill/gap/fees/slippage outcome engine, and all eligible candidates *including abstentions*. If required fields or event-time price cannot be obtained, fail closed rather than impute hindsight. Use session-grouped chronological train/calibration/development folds with purge based on outcome horizon and an untouched final holdout; never feed present-day LLM historical output into an apparent pre-2026 decision. Evaluation is net utility, exposure, turnover, drawdown, calibration and independent event/session counts, including adverse regimes. Positive development result alone does not authorize broker-paper or live trading. Explicit Neal approval remains required for execution and capital changes.
